# 朝の会 体調確認アプリ ☀️

特別支援学校小学部の朝の会などで、子どもたちが直感的かつ楽しく自分の体調や気持ちを伝えるためのWebアプリケーションです。

---

## 🌟 特徴・機能

1. **上段3つ・下段4つの大きなカード配置**
   - 上段：「げんき」「かぜぎみ」「ねむい」の3項目
   - 下段：「わくわく」「おなかすいた」「かなしい」「つかれた」の4項目
   - タブレットや電子黒板、大型モニターでも見やすいユニバーサルデザイン。

2. **楽しいインタラクション**
   - タップ（クリック）すると、明るい効果音（Web Audio API）とキラキラ・花吹雪のエフェクトが発生します。
   - ブラウザの音声合成機能（Web Speech API）により、選んだ項目をやさしい日本語音声で読み上げます。

3. **朝の会の進行をサポートするモーダル表示**
   - カードを選ぶと、画面中央に大きく結果が表示されます。
   - 「👉 つぎの おともだち」ボタンを押すと、スムーズに次の児童に交代できます。

4. **画像の自由な差し替え**
   - `images/` フォルダにご自身で用意した画像を置くだけで、自動的に反映されます。
   - 画像が未配置の状態でも、見やすい絵文字アイコンがフォールバック表示されます。

5. **便利なコントロール**
   - 🔊 **おんせい ON/OFF**: 静かにしたい場面では音声をワンタップで消音できます。
   - ⛶ **ぜんめん**: ブラウザを全画面表示にして、子どもたちが誤って他のタブやアドレスバーを押すのを防ぎます。

---

## 🚀 使い方

### 1. アプリの起動
- `index.html` ファイルをダブルクリックするか、ブラウザ（Google Chrome, Microsoft Edge, Safari など）にドラッグ＆ドロップして開いてください。
- iPadなどのタブレットで使う場合は、Safariで開いて「ホーム画面に追加」すると全画面アプリのように使えます。

### 2. ご用意された画像の配置
`images/` フォルダの中に、以下のファイル名で画像を保存してください：

| 項目 | ファイル名 |
| :--- | :--- |
| げんき（元気） | `genki.png` |
| かぜぎみ（風邪気味） | `kazegimi.png` |
| ねむい（眠い） | `nemui.png` |
| わくわく（ワクワク） | `wakuwaku.png` |
| おなかすいた（お腹すいた） | `onaka.png` |
| かなしい（かなしい） | `kanashii.png` |
| つかれた（疲れた） | `tsukareta.png` |

※ 画像形式は背景透過のPNG（`.png`）を推奨します。
