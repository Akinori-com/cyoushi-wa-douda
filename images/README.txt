【画像の配置方法】

このフォルダに以下のファイル名で画像を保存すると、自動的にアプリに反映されます。

1. 元気        -> genki.png
2. 風邪気味    -> kazegimi.png
3. 眠い        -> nemui.png
4. ワクワク    -> wakuwaku.png
5. おなかすいた -> onaka.png
6. かなしい    -> kanashii.png

※ 画像形式は PNG（.png）を推奨します（背景が透明なイラストが見栄え良く表示されます）。
※ JPG（.jpg）やSVG（.svg）を使用したい場合は、index.html 内の拡張子をご変更いただくか、PNG形式で保存してください。
※ 画像がまだ置かれていない状態でも、自動的にかわいい絵文字・アイコンが表示されます。
